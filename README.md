# dotfiles

Personal dotfiles managed from `~/dev/dotfiles`.

Live symlinks:

- `~/.config/hypr` -> `~/dev/dotfiles/hypr`
- `~/.config/alacritty` -> `~/dev/dotfiles/alacritty`
- `~/.config/fish` -> `~/dev/dotfiles/fish`
- `~/.tmux.conf` -> `~/dev/dotfiles/tmux/tmux.conf`
- `~/.local/bin/tmux-session-picker` -> `~/dev/dotfiles/tmux/tmux-session-picker.sh`
- `~/.vimrc` -> `~/dev/dotfiles/vim/vimrc`
- `~/.vim` -> `~/dev/dotfiles/vim/vim`

Rollback copies from the initial migration are under `backups/`.
